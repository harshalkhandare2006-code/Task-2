# Laundry Wallah

This is a simple laundry service website made using HTML.

The main purpose of this project is to show the different laundry services,
their prices and also provide a simple booking form for customers.

## What is included

- Welcome section
- About Us section
- Laundry image
- Services list
- Price list table
- Book Now form
- Footer with contact information

## Services

The website includes services like:

- Washing and Drying
- Ironing and Folding
- Dry Cleaning
- Stain Removal
- Express Services
- Special Customer Care

## Technologies Used

- HTML5
